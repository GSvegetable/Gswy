# Changelog

## 0.3.0

- Refine uppercase C terminals and correct the G opening, crossbar, and spur.
- Redesign the ampersand as an original e/t-derived ligature.
- Expand the rendered inspection workflow for Latin letters, numerals, punctuation, and accented characters.

## 0.2.0

- Replace raw ASCII punctuation glyph names with Adobe Glyph List names to prevent missing-glyph fallbacks.
- Redraw numerals 2, 3, and 5 and correct the question-mark contour direction.
- Improve spacing of æ, œ, Æ, and Œ ligatures.
- Add source and compiled-font quality checks, including Unicode mappings, non-empty outlines, UPM, and GPOS kerning.
- Add an interactive browser type tester and automated font build artifacts.
- Keep TTF, OTF, WOFF2, UFO source, and specimen artwork synchronized with source builds.
