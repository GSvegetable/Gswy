## 设计参数

- 字体名：Gswy Serif（Regular 先行，Bold/Italic 二期）
- 风格定位：过渡风格衬线体（Transitional），中等对比、bracketed 衬线，气质介于 Source Serif 与 Georgia 之间，造型原创
- 度量：UPM 1000；cap height 700；x-height 480；ascender 750；descender -220
- 笔画：小写主干约 90，细笔约 28-32；大写主干约 100
- 字符集：当前实现：208 字形（以构建输出为准），覆盖 Basic Latin、常用标点、Latin-1 重音组合与部分扩展字母
- 许可：SIL OFL 1.1
